# ORBiS（旧：キャラシ工房）

クトゥルフ神話TRPG（6版・7版）のキャラクターシートを作って、ココフォリアのコマにそのまま貼り付けられるWebアプリです。

公開URL：https://orbis-locus.github.io/ （2026-11-08 に https://kanno-925.github.io/charasheet/ から引っ越し）

## フォルダ構成

```
src/                     ソースコード（ここを編集します）
  index.html             画面の骨組み（HTML）
  css/                   見た目（files.txt の順に結合）
  js/                    動き（files.txt の順に結合し、1つの即時関数で包みます）
  files.txt              結合する順番
assets/                  画像・音（テーマごとにフォルダを分けています）
  book/                  魔導書テーマ（本・机・紙・インクの画像、ページめくりと書きこみの音）
  wa/                    和風テーマ（景色の絵）
  aqua/                  アクアリウムテーマ（水底の絵 scene.webp・ぼかした切りかえ用 bokeh.webp・水底の光の網 caustics.webp）
supabase/                サーバー（Supabase）の設定SQL。番号順に実行します
cloudflare/              共有リンクのカード用の「中継の入口」（Cloudflare Workers に貼る）
docs/history.md          これまでの変更のあゆみ
build.py                 src/ と assets/ から公開用ファイルを作るスクリプト
CLAUDE.md                Claude に作業を頼むときのメモ

―― ここから下は build.py が作るもの（直接編集しない） ――
index.html, css/, js/    GitHub Pages で公開しているもの
dist/ORBiS.html           ダブルクリックで開ける1ファイル版（画像・音も中に入っています）
```

## 更新のしかた

1. `src/` のファイルを編集する
2. `python3 build.py` を実行する
3. 変更を commit して push すると、GitHub Pages に反映されます

## サーバーの準備（Supabase）

`supabase/` のSQLを、Supabase の SQL Editor で番号順に実行します（何度実行しても大丈夫です）。

- `01-setup.sql`：アカウント・キャラシ・フレンド
- `02-groups.sql`：グループ
- `03-group-invites.sql`：グループへの招待・参加
- `04-ui-layout.sql`：画面の編集モード
- `05-app-roles.sql`：権限（マスター・編集者）
- `06-ui-drafts.sql`：編集者の仮保存・編集で使う画像の置き場所
- `07-avatars.sql`：アカウントのアイコン画像
- `08-group-transfer.sql`：グループの代表をゆずる
- `09-dice-limit.sql`：ダイスの上限回数
- `10-share.sql`：キャラシをリンクで共有する
- `11-share-card.sql`：共有リンクを貼ったときのカード（立ち絵のプレビュー）
- `12-char-secrets.sql`：キャラシの秘匿欄（自分とグループのキーパーだけが読める）
- `13-secret-open.sql`：秘匿を「公開する／しない」（公開すると、キャラシを見られる人も読める）

`cloudflare/share-worker.js` は、共有リンクのカードを出すための「中継の入口」です。Cloudflare Workers に貼り付けて使います（GitHub Pages だけではキャラごとのカードを出せないため）。
