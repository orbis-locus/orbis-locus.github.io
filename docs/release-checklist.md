## 1. 権利・表記
- 【必須】権利表記（KADOKAWA の案内の全文）をアプリの画面・BOOTHの説明・同梱の説明書に入れる
- 【必須】「公式」「公認」と読める表現がないか確認する
- 【必須】ルールブックの文章を丸写ししている所がないか確認（技能の説明文など）
- 【推奨】「いあきゃら・ココフォリアは各運営者のサービスで、本ツールは非公式」と書く
- 【推奨】TRPGライツ事務局に「無料のキャラシ作成ツールを配ってよいか」を確認しておく

## 2. 利用規約・個人情報
- 【必須】プライバシーポリシー（メールアドレス・ユーザー名・画像を集めているため）
- 【必須】利用規約（禁止事項、データが消えても責任を負わない、サービスを止めることがある など）
- 【必須】問い合わせ先（専用のメールアドレスかフォーム。本名や個人のアドレスは出さない）
- 【推奨】アカウントを自分で消せる機能（今はない。消したい人への対応手段が必要）

## 3. ドメイン・メール
- 【推奨】独自ドメイン（今は orbis-locus.github.io。独自ドメインにするなら年1,500円前後）
- 【必須】Supabase の Authentication → URL Configuration の Site URL / Redirect URLs を公開URLに合わせる（ドメインを変えたら必ず直す。確認メールのリンク先になる）
- 【必須】確認メールが知らない人にも届くか確かめる。Supabase標準のメール送信は送れる数や宛先に制限があるので、届かなければ独自のメール送信（SMTP。Resend など）を設定する
- 【推奨】確認メールの文面と差出人名を日本語・アプリ名に変える

## 4. 荒らし・迷惑行為への対策
- 【必須】ユーザー名・グループ名・アイコン画像に、不適切なものを入れられた時の対応（通報の手段と、マスターが消せる機能）
- 【推奨】ブロック機能（特定の人からのフレンド申請・招待を受けない）
- 【推奨】フレンド申請・グループ招待の連打を止める（1日の回数の上限をサーバー側で）
- 【推奨】新規登録のボット対策（Supabase の CAPTCHA：Cloudflare Turnstile など）
- 【推奨】ユーザー名の禁止語チェック（ひどい言葉・なりすまし用の「運営」「公式」など）
- 【あとで】マスター用の「利用停止（BAN）」機能

## 5. セキュリティ・マルウェア対策
- 【必須】配るファイルは BOOTH だけから。説明書に「BOOTH以外で手に入れたファイルは開かないで」と書く（書きかえたファイルを再配布されるおそれ）
- 【必須】他人のデータが表示される所（フレンドのキャラシ・グループ・ユーザー名・取り込んだテキスト）で、HTMLとして実行されないか点検する（XSS）
- 【必須】サーバーに入る大きさの上限をサーバー側でも決める（アイコン画像・キャラシ1件・Storage の ui-assets はファイルの大きさと種類＝画像だけ）
- 【推奨】画面の編集モードの値（部品の住所・画像URL）に、CSSを壊す文字や外部の追跡用URLが入らないよう、保存時にチェックする（マスター・編集者しか書けないが念のため）
- 【推奨】RLS（サーバー側の見える範囲・書ける範囲）を全部の表で見直す。とくに有料化の前
- 【推奨】Supabase のパスワードの最低文字数・漏えいパスワードの拒否を設定で確認

## 6. サーバーの容量・費用・バックアップ
- 【必須】Supabase の無料枠の上限を確認：データベース約500MB。立ち絵が data URL でキャラシの中に入っているので、クラウド保存する人が数十人でいっぱいになるおそれ → 立ち絵は Storage に分けて置く／1人あたりの上限を決める
- 【必須】無料プロジェクトは長く使われないと一時停止される。止まった時の案内と、監視の方法を決める
- 【推奨】定期的なバックアップ（無料枠は自動バックアップが限られる）
- 【推奨】料金がかかり始める目安を把握し、上限（Spend cap）を設定する

## 7. 使いやすさ・動作
- 【必須】1ファイル版（ダブルクリックで開く版）でログイン・フレンド・クラウド保存が動くか確認
- 【必須】iPhone（Safari）・Android（Chrome）・パソコンで、全テーマを一通り確認（古いスマホで重くないか）
- 【推奨】データのバックアップ（書き出し）を目立つ所に。端末を変えた時・ブラウザのデータを消した時に失われることを説明
- 【推奨】使い方の説明（最初の1回だけ出る案内や、説明書）
- 【推奨】エラーが起きた時に、利用者が報告できる手段
