できた所に ✅ を付ける。おかしい所は、端末の名前・テーマ・どこで・どうなったか（画像があればそれも）を Claude に伝える。

## Claude が自動で確かめたこと（2026-11-12）
- 全テーマ（ORBiS・近未来・和風・魔導書・アクアリウム・ドット）×パソコン（1366px）・iPhone 13・Pixel 7 の大きさで、探索者をえらぶ画面の3つのタブ・キャラシ・9つの項目の窓・10個の小窓を開いて、エラーと横のはみ出しを確認：エラー0。魔導書のパソコンで、回る魔法陣の角が右にはみ出していたのを直した。
- 1ファイル版（dist/ORBiS.html）を開いて、サーバーにつながること（画面の編集の内容の読み込み・ログインの問い合わせに返事が来る）。
- ブラウザは Chrome のしくみで、端末の大きさをまねしただけ。iPhone の Safari そのもの・指でさわったときの動き・音・重さは確かめられていない。

## 1. iPhone（Safari）
- [ ] 公開サイトを開いて、はじめの画面 →「ORBiS をひらく」→ 探索者をえらぶ画面まで進める（曲が流れる・止められる）
- [ ] 新しい探索者を作って、名前・能力値・技能を入れる（入力するとき、画面が勝手に大きくならない）
- [ ] 9つの項目の窓を開いて閉じる。長い項目（技能・経歴）を指でスクロールできる
- [ ] 「ココフォリア用にコピー」→ ココフォリアに貼れる
- [ ] ログイン → 別の端末（パソコンなど）でも同じ探索者が出る。片方で書きかえると、もう片方にも出る（1分くらい待つか、画面を開き直す）
- [ ] フレンドの申請を送る／受ける（お友達かテスター用のアカウントで）
- [ ] 共有リンクを作って、LINE に貼るとカード（立ち絵の画像）が出る。押すと開ける
- [ ] 重くないか（スクロールや窓を開くときにカクカクしない）。古い iPhone があればそれでも
- [ ] ホーム画面に追加 → アイコンが ORBiS の新しいアイコン、そこから開ける

## 2. Android（Chrome）
- [ ] 1 と同じことを、ざっと（とくに入力・コピー・ログイン・共有リンク）

## 3. パソコン
- [ ] Chrome・Edge（・あれば Mac の Safari）で公開サイトを開いて、1 と同じことをざっと
- [ ] 1ファイル版：BOOTH で配る `dist/ORBiS.html` をダウンロードしてダブルクリック → 開ける・探索者を作れる
- [ ] 1ファイル版でログイン → 公開サイトと同じ探索者が出る・フレンドの一覧が出る
  - 1ファイル版で新規登録すると、確認メールのリンクは公開サイトのほうで開く（それでよい）。確認のあと、1ファイル版にもどってログインする
- [ ] 1ファイル版でバックアップの書き出し・読み込み
