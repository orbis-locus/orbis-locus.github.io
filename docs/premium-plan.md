## 決まったこと（有料版）
- **売り方**：BOOTHで**買い切り**（300〜800円くらい。金額はオーナーが決める）。
- **BOOTHで売るのは「プレミアムを解放する権利」**。Web版（GitHub Pages）は無料のまま残し、無料版と有料版を同じアプリの中で分ける。BOOTHの商品には、解放のしかたを書いた説明（PDFかテキスト）を入れる。
- **有料にする機能**（それ以外は無料のまま）
  1. 特別なテーマ（魔導書 `book` など。どのプリセットを有料にするかはオーナーに確認）
  2. フレンド・グループ（オンライン表示を含む）
  3. クラウド保存（キャラシのサーバー同期）
- **購入確認**：買った人がアプリで**BOOTHの注文番号**を入力して申請 → マスターがBOOTHの管理画面で注文を確かめて、アプリの中で「承認」する（手動）。
- マスター・編集者（`app_admins` の人）は、最初からプレミアム扱い。

## 作るもの
### サーバー（`supabase/07-premium.sql`）
- `premium_users`（user_id, granted_at, granted_by, order_no）：プレミアムの人。
- `premium_requests`（user_id, order_no, created_at, status: pending/approved/rejected）：申請。自分の分だけ書ける・見られる。マスターは全部見られる。同じ注文番号の使い回しは防ぐ（order_no に unique）。
- `is_premium()`：`premium_users` にいるか、`app_admins` にいれば true。
- `my_premium()`、マスター用の `premium_request_list()`・`approve_premium(target)`・`reject_premium(target)`（security definer、マスター以外は何もしない）。
- **RLSでサーバー側でも制限する**（コードは公開なので、画面で隠すだけでは足りない）：
  - `characters` の insert/update は `is_premium()` が必要（クラウド保存）。自分のキャラの読み出し・削除は今まで通り（有料でなくなっても自分のデータは取り出せるように）。
  - フレンドのキャラを見る（chars read の friend 部分）、`friendships` の insert/update、`groups` の insert、`group_members` の insert は `is_premium()` が必要。
  - 既存の policy を drop → create し直す。01〜03 のSQLの policy 名に合わせる。

### アプリ
- ログイン時に `my_premium()` を見て `me.premium` を持つ。localStorage にも覚えておき、オフラインでも前回の状態を使う。
- **特別テーマ**：無料の人はテーマ一覧で鍵マークを出し、押すと購入の案内を出す。無料の人が有料テーマのままなら、起動時に通常テーマに戻す（この制限は画面側だけ。コードが公開なので詳しい人は外せる。オーナーには説明済みにすること）。
- **フレンド・グループ・クラウド保存**：無料の人には、エラーではなく「プレミアムで使えます」の案内を出す。
- **購入・解放の画面**：BOOTHの商品ページへのリンク（URLは定数 `BOOTH_URL`。オーナーから聞く）、ログインが必要なことの説明、注文番号の入力欄、申請後は「確認待ち」「承認ずみ」「却下」を表示。
- **マスター用**：編集パネルのタブに「購入者」を足し、申請の一覧（ユーザー名・注文番号・日時）と「承認」「却下」ボタンを出す。
