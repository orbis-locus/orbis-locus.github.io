## 商品説明（本文）
```
探索者を、つぎの世界へ。

ORBiS（オルビス）は、クトゥルフ神話TRPG（6版・7版）の探索者のキャラクターシートを作って、ワンクリックでココフォリアのコマにできるツールです。
ダウンロードした1つのファイルをダブルクリックするだけで使えます。スマホからは Web 版でどうぞ。

▼ Web 版（インストールなしで、いますぐ使えます）
https://orbis-locus.github.io/

━━━━━━━━━━━━━━━━━━━━
■ できること
━━━━━━━━━━━━━━━━━━━━
・6版・7版の探索者を作成（HP・MP・SAN・技能ポイント・ダメージボーナスは自動計算）
・ボタン1つでココフォリアのコマにコピー（チャットパレット入り）
・いあきゃらからの取り込み（テキスト出力の .txt なら、技能の内訳・武器・所持品・経歴まで丸ごと）
・能力値・技能のグラフ、立ち絵と表情差分、キャラごとの BGM
・キャラシの中でダイスを振れる
・アカウントを作ると、パソコンとスマホで同じ探索者を使える（クラウド保存）
・フレンドの申請、キャラシの共有リンク（LINE や Discord に貼ると立ち絵のカードが出ます）

━━━━━━━━━━━━━━━━━━━━
■ 無料サンプル版について
━━━━━━━━━━━━━━━━━━━━
いまは無料のサンプル版です。
・テーマは「ORBiS」、探索者は3人まで
・次の機能は「製品版で解放予定」です：ほかのテーマ（和風・魔導書・アクアリウム・ドットなど）、探索者4人以上、グループ（シナリオごとの記録・キーパーの機能）、フレンドのキャラシを見る
アプリの中の「欲しい！」ボタンを押していただくと、製品版を作るかどうかの参考にさせていただきます。

━━━━━━━━━━━━━━━━━━━━
■ 使い方
━━━━━━━━━━━━━━━━━━━━
1. ORBiS.html をダウンロードして、ダブルクリック
2. 「新しい探索者」から6版か7版を選んで、能力値や技能を入力
3. 「ココフォリア用にコピー」を押して、ココフォリアの盤面に貼り付け（Ctrl+V）
くわしくは、いっしょに入っている「はじめにお読みください.txt」をご覧ください。
```
