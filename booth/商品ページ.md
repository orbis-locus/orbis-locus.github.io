探索者を、つぎの世界へ。

ORBiS（オルビス）は、クトゥルフ神話TRPG（6版・7版）の探索者のキャラクターシートを作って、ワンクリックでココフォリアのコマにできるツールです。
ダウンロードした1つのファイルをダブルクリックするだけで使えます。スマホからは Web 版でどうぞ。

▼ Web 版（インストールなしで、いますぐ使えます）
https://orbis-locus.github.io/

・ボタン1つでココフォリアのコマにコピー（チャットパレット入り）
・いあきゃらからの取り込み（テキスト出力の .txt なら、技能の内訳・武器・所持品・経歴まで丸ごと）
・能力値・技能のグラフ、立ち絵と表情差分、キャラごとの BGM
・キャラシの中でダイスを振れる
・アカウントを作ると、パソコンとスマホで同じ探索者を使える（クラウド保存）
・フレンドの申請、キャラシの共有リンク（LINE や Discord に貼ると立ち絵のカードが出ます）
